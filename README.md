Module 02 – Linux, Security Tools & Reconnaissance

Project: Controlled Reconnaissance Lab

About

This project is part of Module 02 of my cybersecurity learning journey. It focuses on Linux fundamentals, reconnaissance concepts, and essential security tools through a controlled and authorized lab environment.

Objectives

1. Learn Linux fundamentals:
   
   - Files and directories
   - Permissions
   - Users and groups
   - Processes
   - Security basics

2. Understand reconnaissance:
   
   - Passive and active reconnaissance
   - DNS and domain information gathering
   - Network enumeration

3. Learn essential security tools:
   
   - Nmap
   - Wireshark
   - Burp Suite
   - OWASP ZAP

4. Build a Controlled Reconnaissance Lab to safely discover, analyze, and document security findings.

Tools

- Linux (Ubuntu)
- Nmap
- Wireshark
- Burp Suite
- OWASP ZAP

Project Scope

All practical activities will be performed only in my own virtual lab or authorized training environments.

Project Status

In Progress

Learning Outcome

To understand basic Linux security, reconnaissance techniques, and the use of essential cybersecurity tools.
